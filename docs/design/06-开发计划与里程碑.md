# 06 · 开发计划与里程碑

## 1. 总原则

1. **先规则、后表现、再风格。**
2. **新建规则模块**，不在 `FishRushModel` 上缠射击分支。
3. 每完成一个里程碑：更新本文「状态」列，并对照 `03` 验收清单。

## 2. 技术落点（建议）

| 模块 | 建议路径/职责 |
|---|---|
| 规则层 | `assets/scripts/ZombieGateModel.ts`（名称可调）：格子、门、敌、射击、胜负 |
| 关卡数据 | 同文件常量或 `assets/scripts/ZombieGateLevel.ts`：门行/敌行表 |
| 画面描述 | `ZombieGatePresentation.ts`：车道、门、敌、HUD 的 2D 描述 |
| Cocos 适配 | `ZombieGateGame.ts` 或阶段性替换 `FishRushGame` 入口 |
| 测试 | `tests/zombie-gate.cjs`：门结算、换道、击杀、撞线、胜负 |
| 预览 | 扩展 `tools/preview.cjs` / `preview/index.html` 切换新模式 |
| 策划案 | `docs/design/*`（本目录） |

保留 `FishRush*` 直至新模式验收通过；切换主场景入口前两套可并存。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 追击过快导致必输 | 降 `chaseSpeed`、加 `AGGRO_RANGE`、提高开局火力 |
| 翻倍后数值崩 | `maxUnits` + 伤害软顶 |
| 与旧代码纠缠 | 新模块并存，验收后切入口 |
| 伪 3D 又带回「谁在动」混乱 | 逻辑只用格子/世界 y；透视仅投影 |
| 范围膨胀（顺便做 Boss） | 严格按 `03` Out of Scope |
