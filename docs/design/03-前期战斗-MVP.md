# 03 · 前期战斗 MVP

> 目标：先独立做出「向僵尸开炮」前期——过门攒实力 + 自动射击清普通怪。不含 Boss。

## 1. 范围

### In Scope

- Ready / Playing / Won / Lost
- 5 车道格子移动
- 门：`+N`、`×2`、武器升级、射速（至少实现前 3 种；射速可并入武器档）
- 自动射击（瞬时命中或短弹道）
- 普通敌 1 种（可选厚皮 1 种）
- 撞前线扣人
- 45～60 秒一局，无 Boss
- 规则层单测 + preview 可玩

### Out of Scope

- Boss、精英技能、三选一、局外成长
- 手动瞄准、复杂弹道物理
- 完整新美术管线（可用色块/现有精灵占位）

## 2. 一局流程

1. 点击开始 / Enter / 空格 → `playing`
2. 玩家沿地图前进，左右换道
3. 经过门行 → 结算所在侧门效果
4. 进入射程的敌人被自动射击；HP≤0 移除
5. 敌人接触玩家前线 → `unitCount -= touchCost`
6. `unitCount <= 0` → `lost`；`elapsed >= duration` 且仍存活 → `won`
7. 失败重开本关；胜利可先只显示结算（进下一关留到后续）

## 3. 核心状态（建议）

```ts
phase: 'ready' | 'playing' | 'won' | 'lost'
elapsed: number
unitCount: number
weaponTier: number          // 0..2
fireCooldown: number
playerLane: number          // 0..4
playerY: number             // 连续前进
gates: GateEntity[]         // 地图静止
enemies: EnemyEntity[]      // 静止或追击
score: number               // 击杀与成长 integratable
```

## 4. 战斗公式（初稿，可调）

### 4.1 武器档（占位数值）

| Tier | 名称（占位） | damage | interval(s) | pellets |
|---|---|---|---|---|
| 0 | 小水枪 | 1 | 0.40 | 1 |
| 1 | 双喷 | 1 | 0.32 | 2 |
| 2 | 强袭 | 1 | 0.24 | 3 |

子弹默认伤害恒为 1；枪档只改射速与弹数。同一敌人每轮最多吃到 `pellets` 发，避免人数叠乘瞬间融化。

- 每发从「存活单位」中取枪口；首版可简化为：`dps ≈ unitCount * pellets * damage / interval`，表现上最多绘制 `min(unitCount, 16)` 个枪口。
- `maxUnits = 40`；`×2` 超出部分可转为临时 `damageBonus`（可选，防崩）。

### 4.2 普通敌

| 类型 | hp | touchCost | 行为 |
|---|---|---|---|
| 普通飞飞鼠 | 1 | 1 | 前方进入发现距后追击 |
| 厚皮飞飞鼠（可选） | 3 | 2 | 同上，移速略慢 |

### 4.3 扣人与前线

- 前线：`enemy.y <= player.y + FRONT_EPSILON` 且同 lane（或相邻 lane 可配置）。
- 接触一次结算后敌人销毁或后退（推荐销毁，节奏更脆）。

## 5. 关卡时间轴（60 秒草案）

前进速度：约每 1.0s 推进 1 行逻辑行（具体用 `playerY` 连续值换算）。

| 时间 / 行 | 内容 |
|---|---|
| 开局 | 5 人，武器 T0 |
| 行 3 | 门：`+3` \| `+5` |
| 行 5 | 敌行：3 只普通（分散车道） |
| 行 7 | 门：`×2` \| 武器+1 |
| 行 9 | 敌行：4 只 |
| 行 11 | 门：`+5` \| 射速/武器 |
| 行 13 | 敌行：5 只（含 1 厚皮可选） |
| 行 15 | 门：武器+1 \| `+3` |
| 行 17+ | 稀疏敌行直至 60s |

门与敌行交替，避免连续三行全是门导致无战压。

## 6. 操作与 UI

- 滑动 / 方向键 / A·D：换道
- 开始、失败重开、胜利确认
- HUD：人数、武器档、剩余时间或进度
- 反馈：命中飘字、过门飘字、撞线闪红

## 7. 验收清单

- [x] 门在逻辑上坐标固定；相机/玩家前进导致相对屏幕移动
- [x] 左右换道按格，不等同旧版无级 `x ∈ [-1,1]` 滑轨手感
- [x] `+` / `×` / 武器门效果正确，有单测
- [x] 自动射击能击杀普通敌
- [x] 追击仅在发现后发生；未发现敌不主动贴脸（站岗可见）
- [x] 撞线扣人，扣光失败
- [x] 存活到时长胜利
- [x] preview 与规则测试可跑通
- [x] 无 Boss 相关分支或仅预留空接口

## 8. 惩罚选择：扣人 vs 血条

**MVP 采用扣人制。**  
理由：与「过门加人」同一货币，决策清晰。若实机发现挫败过强，再引入薄血条作缓冲（文档修订后改）。
