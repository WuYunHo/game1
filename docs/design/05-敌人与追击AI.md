# 05 · 敌人与追击 AI

## 1. 原则

- **出生点相对地图静止**；不是旧版「整波 depth 推向镜头」。
- **未发现玩家**：站岗（idle），可有呼吸/像素帧动画，不改格子坐标。
- **发现大肥鱼后**：进入追击，向玩家移动——这是文档明确允许的「相对地图可动」例外。
- 首期不做复杂绕路，追击以改 `lane` + 减小与玩家的 `y` 差为主。

## 2. 敌人实体

```ts
type Enemy = {
  id: number;
  lane: number;
  y: number;              // 地图坐标，站岗时固定（可含 dy 错落）
  ox: number;             // 同 lane 堆叠的横向视觉偏移（车道宽比例）
  hp: number;
  touchCost: number;
  speed: number;          // 追击速度（世界单位/秒）
  state: 'idle' | 'chase' | 'dead';
  kind: 'normal' | 'tank';
};
```

**密集度**：关卡允许同 lane 多只飞飞鼠，用 `dx`/`dy` 错落堆叠，避免稀疏单排。

## 3. 发现（Aggro）

### 3.1 条件（MVP 建议）

同时满足：

1. 敌人在玩家前方：`enemy.y > player.y`（或行号更大）。
2. 距离：`enemy.y - player.y <= AGGRO_RANGE`（例：3～5 行）。
3. 可选车道限制：`abs(enemy.lane - player.lane) <= 2`（避免身后全图仇恨）。

进入 `chase` 后，MVP **不脱战**（简化）；P1 可再加脱战距离。

### 3.2 未发现时的表现

- 可面向固定方向或巡逻动画，但 **逻辑坐标不变**。
- 仍可被玩家子弹击中；被打是否立即 aggro：建议 **是**（被打发现）。

## 4. 追击移动

每帧（逻辑）：

1. 若 `abs(enemy.lane - player.lane) > 0`：按追击节奏改道（可每 0.2s 向玩家 lane 靠近 1 格，避免瞬移贴脸）。
2. `enemy.y` 向 `player.y` 靠近：`enemy.y -= speed * dt`（若 +y 为前进方向）。
3. 到达前线判定见 `03`。

注意：追击速度应 **低于玩家前进速度 + 一定余量**，否则开局必撞；或玩家前进更快，追击怪从前方「逆行压来」，形成压力。两种手感：

| 模式 | 观感 | 建议 |
|---|---|---|
| 逆行压来 | 更像僵尸潮 | `chaseSpeed` 相对相机有向玩家的分量 |
| 同向追赶 | 更像被咬尾 | 适合侧后刷怪 |

**MVP 推荐：敌人在前方站岗，aggro 后逆行靠近玩家（对玩家形成前线压力）。**

## 5. 受伤与死亡

- 命中：`hp -= damage`；飘字；可选闪白。
- `hp <= 0`：死亡，计分，移除。
- 死亡不挡路。

## 6. 刷怪方式

关卡用**静态敌行**配置（与门行一起编进关卡表），例如：

```ts
{ row: 5, spawns: [ { lane: 0, kind: 'normal' }, { lane: 2, kind: 'normal' }, { lane: 4, kind: 'normal' } ] }
```

不要用「定时在 depth=0 生成再漂过来」作为主模型；若需波次感，用「到达某行时激活下一敌行」即可。
