# 04 · 门与武器成长

## 1. 设计目标

- **门**：左右抉择，既有增益也有减益，避免数值只涨不跌。
- **武器**：不再是过门赠送；地图上出现 **宽度 1 车道** 的武器箱，需射击打碎后获得。

## 2. 门配置表

实现文件：`assets/scripts/ZombieGateConfig.ts` → `GATE_DEFS`。

关卡只引用 **def id**，不散落写 kind/value：

```ts
{ row: 3, left: 'add3', right: 'sub2' }
```

### 2.1 当前种类

| kind | 例 | 效果 | good |
|---|---|---|---|
| `add` | `+2` `+3` `+5` | `unitCount += value`（≤ maxUnits） | true |
| `sub` | `−1` `−2` `−5` | `unitCount -= value`（≥ 0；到 0 失败） | false |
| `mul` | `×2` | `floor(unitCount * value)` | true |
| `div` | `÷2` | `floor(unitCount / value)` | false |

新增门类型：先在 `GATE_DEFS` 加一行，再在 `LEVEL_1.gates` 引用。

### 2.2 排布与结算

- 一门行左右两扇；按 `playerLane` 所属侧结算（0–2 左，3–4 右）。
- 门相对地图静止；玩家越过该行结算一次。

## 3. 武器箱（可打碎）

配置：`WEAPON_CRATE_DEFS` + 关卡 `weaponCrates`。

| 字段 | 规则 |
|---|---|
| 宽度 | **1 车道** |
| 默认 HP | **20** |
| 行为 | 地图静止；进入射程后可被大肥鱼子弹击打 |
| 打爆 | `weaponTier = max(current, crate.tier)`，获得对应枪 |

关卡例：

```ts
{ row: 8, lane: 1, crate: 'dual' }      // tier 1, hp 20
{ row: 28, lane: 2, crate: 'assault' }  // tier 2, hp 20
```

武器箱 **不是门**，不占用左右门抉择。

## 4. 人数规则

```
initialUnits = 5
maxUnits     = 40
```

减益可把人数打到 0 → 本关失败。

## 5. 武器档位

见 `03`：伤害恒为 1；档位差在射速 / 弹数 / 颜色。  
获取途径：**打碎武器箱**，不再有 `weapon` 门。
