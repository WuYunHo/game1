# 01 · 玩法总览

## 1. 核心循环

```
换道移动 → 穿过门（人数 / 武器）→ 自动射击前方敌人
       → 敌人撞前线则掉人（或掉血）→ 人尽失败 / 撑过关时胜利
```

远期完整循环（首期不做括号内）：

```
前期过门成长 → 中期火力清潮 → （Boss 对决）→ （下一海域）
```

## 2. 阶段划分

| 阶段 | 目标 | 状态 |
|---|---|---|
| P0 前期战斗 | 门 + 自动射击 + 普通敌 + 胜负 | **当前开发焦点** |
| P1 Boss | 关末首领、特殊机制 | 后置 |
| P2 表现升级 | 元气骑士式 VFX、更完整关卡段 | 后置 |
| P3 运营向 | 排行榜维度、更多武器/敌人皮肤 | 可选 |

## 3. 玩家行为

- **移动**：仅左右换道（离散格子）；沿关卡前进轴自动推进（或由相机相对前进体现）。
- **射击**：全自动；朝正前方车道优先，其次最近敌人。
- **决策**：选哪扇门（左/右）、是否绕开高危追击怪（若有空道）。

## 4. 成长维度

1. **人数 `unitCount`**：枪口数量（及可选的撞击抗性）。
2. **武器 `weaponTier`**：单发伤害、弹道数（pellets）。
3. **射速 `fireRate`**：攻击间隔缩短。

首期成长几乎全部来自**门**；不做三选一强化（可放 P1/P2）。

## 5. 对抗维度

- 普通飞飞鼠：有血量，可被打死；可站岗或发现后追击。
- 撞线惩罚：推荐 **扣人制**（与过门加人强绑定）。备选共享血条见 MVP 文档。
- 失败：`unitCount <= 0`。
- 胜利（无 Boss 版）：存活至关卡时长，或清理完预定波次/行数。

## 6. 与旧版肥鱼玩法的关系

| 旧版 | 新版 |
|---|---|
| 鱼群人数是唯一战力，靠撞结算 | 人数是火力单元，靠射击结算 |
| 门只有 + / × | 门增加 weapon / firerate |
| 遭遇物用 depth 推向玩家 | 地图坐标静止，玩家/相机前进 |
| 伪 3D 透视水道 | 可保留装饰透视，但逻辑必须是格子地图 |

旧版可作为预览对照或隐藏模式，但**主线规则新建**，避免双核耦合。
