# 00 · 产品定位与目标

## 1. 一句话定位

竖屏格子射击成长关：控制 DeepSeek 大肥鱼小队左右换道、向前推进；过门积攒人数与武器；自动开火清理飞飞鼠；**画面追求元气骑士式清晰反馈，玩法主核对齐向僵尸开炮的前期战斗**。

## 2. 参考拆解

| 来源 | 要借 | 首期不借 |
|---|---|---|
| 向僵尸开炮 | 过门攒实力、自动射击、波次推进、火力成长手感 | 重度合成树、商业化养成、完整 Boss 战（后置） |
| 元气骑士 | Q 版/像素可读剪影、命中飘字、枪口与受击反馈、高对比色块 | 完整地牢 Roguelike、海量武器池、四向复杂操作 |
| 现有肥鱼项目 | IP（肥鱼/飞飞鼠）、竖屏 720×1280、Model/Presentation 分层、微信排行榜基建 | 人数冲关伪 3D 卷轴、加减门即唯一成长、无射击 |

## 3. 产品目标

### 3.1 玩家体验目标

- 前 10 秒理解：左右换道、过门变强、自动开枪。
- 前 60 秒体验到：人变多 / 枪变强 → 清怪变爽；撞线掉人 → 有压力。
- 不出现「分不清谁在动」的空间违和。

### 3.2 研发目标（独立开发）

- 先做**可玩的前期战斗垂直切片**，再叠 Boss 与画面风格强化。
- 规则层可单测；预览与 Cocos 共用同一套规则描述。
- 控制首期内容量：1 套地图规则、≤3 档武器、1～2 种普通敌、无 Boss。

## 4. 明确不做（首期）

- Boss / 精英技能战
- 手动瞄准、换弹、掩护、四向自由移动
- 超过 3 档的武器树、局外养成
- 完整像素重制全部美术（先保证网格与反馈，再迭代贴图）
- 在旧 `FishRush*` 上堆射击分支导致双玩法缠死

## 5. 成功标准（前期切片）

满足 `03-前期战斗-MVP.md` 验收清单，且：

1. 空间关系符合 `02-空间与镜头.md`（门静止、追击例外清晰）。
2. 过门成长与射击手感可感知（弱枪 / 强枪差异明显）。
3. 一局 45～60 秒可完整体验：开始 → 成长 → 清怪压力 → 胜/负 → 重开。
